Part 1/2 – the live viva: the student records each answer in the Web App, the Web App uploads the audio to the Backend API, the backend stores the audio in Cloudflare R2, saves the answer sheet in the DB and asks the AI Engine to transcribe the speech and generate the next question, then the feedback goes back to the Web App. Visual Paradigm style: light-blue participant boxes, dashed life lines, messages numbered 1: → 23: (solid = call, dashed = return).

6 lifelines (incl. DB) · 3 phases

ParticipantResponsibility
StudentOpens the viva room, records each answer, reads the feedback and finishes the session
Web AppRecords the audio, uploads it in chunks, submits the answer, shows the feedback + the next question
Backend API (ASP.NET Core)Orchestrates: initialises the upload, stores the audio, calls the AI, returns the feedback + the next question
DB (PostgreSQL / Neon)Session, Question, Answer (PROCESSING), Result (PENDING_REVIEW)
Cloudflare R2Stores the viva audio (object key) – the evidence source for the examiner
AI Engine (FastAPI)Transcribes the speech (STT) + generates the rubric follow-up question
