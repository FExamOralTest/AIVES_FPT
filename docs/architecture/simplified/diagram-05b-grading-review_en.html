8 lifelines & 4 phases

ParticipantResponsibility
Finish handlerTakes the finish request and stores the submission in the Result store
Hangfire (queue grading)Job queue for the grading job; the worker retries at 30s / 120s / 300s (max 3 attempts)
Back-end Service (Grading)Orchestrates the grading: loads the result + rubric, calls the AI, stores the score, flags FAILED/ERROR when the retries run out
AI serviceGrades against the rubric, returns the score + feedback + suggestions per answer
Result storeKeeps the AI score + feedback, serves the examiner review and hands the result to the student
DB (PostgreSQL / Neon)Session, Question, Answer, Result (PENDING_REVIEW → EVALUATED → REVIEWED → PUBLISHED)
ExaminerAuthorizes the AI grading (without this the AI must not grade), listens to the evidence, assigns the official score, publishes the result
StudentReads the score + the examiner comment once the result is published
