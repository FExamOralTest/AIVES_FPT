C1 Container shows AIVES deployed as 4 containers (frontend · backend · ai-service · postgres) plus the external services (Neon PostgreSQL · Cloudflare R2 · LLM). The notes cover the Hangfire queue and the internal Backend ↔ AI protocol.

Containers & responsibilities

ContainerResponsibility / configuration
Web ApplicationReact 19 SPA + Nginx — serves the viva room, exam management and the examiner review portal; reverse-proxies /api and /uploads to the backend
Backend Web APIASP.NET Core 8 — JWT auth, RBAC, session orchestration, presigned URL signing; it also hosts **two Hangfire servers**: aives-api-* (5 workers, queues default + answers) and aives-grading-* (1 worker, queue grading)
Message Queue / Job StorageHangfire stores jobs in the PostgreSQL schema hangfire — QueuePollInterval = 2s, InvisibilityTimeout = 10m, retry 30s → 120s → 300s for at most 3 attempts (BR-17)
AI Worker & Inference ServicePython FastAPI — Faster-Whisper STT, TTS and rubric grading with an LLM; internal only, never published to the internet
Relational DatabaseNeon PostgreSQL — users, RBAC, exams, sessions, answers (status, audio_url) and scores

Docker Compose topology

ServicePorts & notes
frontendStatic React SPA build served by Nginx on :80 (host :5173 in dev)
backendASP.NET Core 8 on :8080 (host :5000), hosting the Hangfire servers + Swagger
ai-serviceFastAPI / uvicorn on :8000, reachable only internally through the Docker DNS name http://ai-service:8000
postgresPostgreSQL 16 (profile local-db); by default the managed Neon PostgreSQL is used

Internal Backend ↔ AI protocol

ItemDetail
Base URLInternal Docker DNS — http://ai-service:8000 (never published to the internet)
Auth headerX-Internal-Token: <AI_SERVICE_SECRET_KEY> on every /ai/* request
POST /ai/speech/transcribe-objectAccepts { answerId, objectKey }, pulls the file from R2 via the S3 API and runs STT; returns the answer transcript
POST /ai/evaluate/sessionGrades against the session rubric and returns the AI score + comments
POST /ai/interview/follow-upGenerates the next interview question from the rubric and the current answer
TimeoutAI__TimeoutSeconds = 300 seconds per call
Error taxonomyRetryable: timeout · connection_error · internal_error · http_error; non-retryable errors go to the dead-letter queue
QueueSTT and grading jobs run in the background through Hangfire (schema hangfire), retry 30s → 120s → 300s for at most 3 attempts (BR-17)
