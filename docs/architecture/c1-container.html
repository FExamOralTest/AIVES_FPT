C1 Container cho thấy AIVES được deploy thành 4 container (frontend · backend · ai-service · postgres) cùng các dịch vụ bên ngoài (Neon PostgreSQL · Cloudflare R2 · LLM). Phần ghi chú mô tả hàng đợi Hangfire và giao thức nội bộ Backend ↔ AI.

Container & trách nhiệm

ContainerTrách nhiệm / Cấu hình
Web ApplicationReact 19 SPA + Nginx — phục vụ giao diện phòng thi, quản lý ca thi và cổng thẩm định của khảo thí; reverse proxy /api và /uploads về backend
Backend Web APIASP.NET Core 8 — xác thực JWT, RBAC, điều phối ca thi, ký presigned URL; đồng thời chạy **hai Hangfire server**: aives-api-* (5 worker, queue default + answers) và aives-grading-* (1 worker, queue grading)
Message Queue / Job StorageHangfire lưu job trong PostgreSQL schema hangfire — QueuePollInterval = 2s, InvisibilityTimeout = 10m, retry 30s → 120s → 300s tối đa 3 lần (BR-17)
AI Worker & Inference ServicePython FastAPI — Faster-Whisper STT, TTS và chấm điểm rubric bằng LLM; chỉ nội bộ, không public ra Internet
Relational DatabaseNeon PostgreSQL — users, RBAC, đề thi, ca thi, câu trả lời (status, audio_url) và kết quả chấm

Topology Docker Compose

ServiceCổng & ghi chú
frontendReact SPA build tĩnh, Nginx phục vụ trên cổng :80 (host :5173 khi dev)
backendASP.NET Core 8 trên :8080 (host :5000), chứa Hangfire server + Swagger
ai-serviceFastAPI / uvicorn trên :8000, chỉ truy cập nội bộ qua Docker DNS http://ai-service:8000
postgresPostgreSQL 16 (profile local-db); mặc định dùng Neon PostgreSQL quản lý

Giao thức nội bộ Backend ↔ AI

Hạng mụcChi tiết
Base URLNội bộ Docker DNS — http://ai-service:8000 (không public ra Internet)
Header xác thựcX-Internal-Token: <AI_SERVICE_SECRET_KEY> trên mọi request /ai/*
POST /ai/speech/transcribe-objectNhận { answerId, objectKey }, tự kéo file từ R2 qua S3 API rồi chạy STT; trả transcript cho câu trả lời
POST /ai/evaluate/sessionChấm điểm theo rubric của ca thi, trả điểm AI + nhận xét
POST /ai/interview/follow-upSinh câu hỏi phỏng vấn tiếp theo dựa trên rubric & câu trả lời hiện tại
TimeoutAI__TimeoutSeconds = 300 giây cho mỗi lần gọi
Phân loại lỗiRetry được: timeout · connection_error · internal_error · http_error; lỗi không retry đưa vào dead-letter
Hàng đợiJob STT & chấm điểm chạy nền qua Hangfire (schema hangfire), retry 30s → 120s → 300s, tối đa 3 lần (BR-17)
