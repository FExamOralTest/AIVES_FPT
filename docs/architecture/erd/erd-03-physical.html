Đặc điểm của mức vật lý

  • Ánh xạ 1:1 với schema thật trên Neon: 21 bảng trong schema public.
  • Hiển thị kiểu dữ liệu PostgreSQL cụ thể: integer, bigint, varchar(n), text, jsonb, text[], real, numeric(8,4), timestamptz và các enum do ứng dụng định nghĩa.
  • Ghi rõ PK, UNIQUE, FK kèm quy tắc ON DELETE (CASCADE / SET NULL / RESTRICT) và các CHECK constraint.
  • Bảng được nhóm theo package theo tên bảng thật (public.users, public.results, …).
