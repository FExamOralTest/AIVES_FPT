🎓 AIVES v2.0 — Static Workflow Data Models (WF-01, WF-02, WF-03)

Standard Static Association Lines (No Directional Arrowheads) + Relationship Labels

✅ Static Data Model Standards Enforced:
• Nodes (Entities): Strictly static entities (nouns) consistent across the system.
• Relationships (Undirected Association Lines): Static data models use undirected lines (---) without arrowheads (since arrowheads represent dynamic control/data flow). Labels describe the relationship using Verb + Target Entity + Scope.
