Left-to-Right Stage Container / Workspace Frame Who Operates It & Key Operations Protocol
Stage 1 & 2 (Left) React 19 SPA (4 Role Workspaces) • Admin Workspace: User accounts, role assignment, course creation.
• Staff Workspace: Upload .md, review/approve AI questions, schedule multi-slot sessions.
• Student Workspace: Live Viva audio recording (4s chunks), submit exam, view published grades.
• Examiner Workspace: Replay student audio from R2, override AI score with reason, grant retake, publish result. 		HTTPS + JWT Bearer
Stage 3 (Center) ASP.NET Core 8 API + Hangfire Queue + PostgreSQL 16 • Backend API: Validates business rules, merges audio chunks, uploads .webm to R2, enqueues grading job.
• Hangfire Worker: Pulls queued jobs asynchronously (`SessionGradingService`), retries up to 3 times on failure. 		TCP:5432, S3 PutObject, Hangfire Job Queue
Stage 4 (Right-Center) AI Microservice Frame (Python FastAPI :8000) • Question & Rubric Generator: Extracts draft questions + 3–5 rubric criteria from course .md.
• Faster-Whisper STT Engine: Downloads student audio from R2 and transcribes speech to text.
• Rubric Grading & Follow-up Engine: Evaluates transcript against rubric criteria via Gemini and returns structured JSON. 		HTTP:8000 + X-Internal-Token
Stage 5 (Right) Cloudflare R2 & Google Gemini API • Cloudflare R2: Stores student audio files and serves 15-min Presigned URLs to Examiner.
• Google Gemini API: Executes LLM question generation and criterion-level rubric scoring. 		HTTPS S3 API, HTTPS Gemini REST
