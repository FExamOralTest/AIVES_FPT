AIVES V2.0 — SWIMLANE WORKFLOW ARCHITECTURE

Complete, non-technical swimlane specifications: 3 dedicated split flows + unified 10-activity workflow

Flow 1 Specifications: Exam Setup & Administration

Role Activity System Behavior
Admin Manage Users & Roles Creates accounts and grants roles (STAFF, EXAMINER, STUDENT).
Admin Assign Courses Links teachers/staff to responsible courses.
Staff Upload Materials & Rubrics Uploads .md curriculum documents and configures rubric criteria for question bank.
Staff Schedule & Enroll Creates multi-slot exam sessions (session_slots) and assigns student lists.

Flow 2 Specifications: Live Viva Exam & AI Ingestion

Actor Step Technical Specification
Student Join Viva Room Submits session_code; system validates student enrollment and exam slot.
System Play Audio & Save R2 Plays TTS question; receives chunked audio, stores on server disk, and pushes single object to Cloudflare R2.
System (Queue) Grade via Rubric Hangfire async job scores transcript against rubric criteria; saves result as PENDING_REVIEW.

Flow 3 Specifications: Examiner Review & Quality Governance

Actor Step Specification (AIVES v2.0)
Examiner Review AI & Listen Audio Inspects AI rubric points; listens to original audio via secure Presigned GET URLs (Cloudflare R2).
Examiner Override / Incident Can override AI score (requires mandatory comment in audit_logs) or grant technical retake (exam_retakes).
System Lock Result (PUBLISHED) Locks attempt from further changes (immutable lockdown) and enables score visibility for student.
Student View Published Grade Accesses official scorecard, rubric breakdown, and examiner feedback.

Diagram 4 Specifications: 10 Activities & 3 Error Branches

UC Code Actor Activity & Exception Handling
UC-01 Admin Manage accounts, roles (Admin/Staff/Examiner/Student) & course assignments.
UC-02 Staff Upload .md lecture material, trigger AI question & rubric criteria generation.
UC-03 Staff Build multi-slot exam paper & schedule sessions.
UC-04 Staff Enroll students into assigned exam slot sessions.
UC-05 Student Take live viva exam & record audio answers.
Branch 1 System Submit Error (400/403): Student retries if session slot is invalid or unauthorized.
UC-06 System AI transcribes audio (STT) and grades against rubric (Hangfire retry 20s/60s/300s).
Branch 2 System Grading Error (FAILED): If AI fails after retries, examiner manually grades or re-triggers.
UC-07 System Persist graded result in PENDING_REVIEW state and record audit log.
UC-08 Examiner Review student audio evidence (Cloudflare R2) and assign official score.
Branch 3 System Publish Error (409 Conflict): Incomplete evaluation blocks publish; examiner reviews again.
UC-09 Examiner Handle incident: re-grade one answer or grant technical retake (exam_retakes).
UC-10 Student View final verified result (PUBLISHED state) with detailed breakdown.
